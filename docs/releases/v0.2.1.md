# OpenPlatform v0.2.1 预览版

RoboDojo 的 Docker 和 Conda 配方均支持 `collection.safety: true`，默认关闭。两种配方使用同一套 PhysX 张量读取和安全指标汇总，分别输出 `safety-events.jsonl` 与 `safety-metrics.jsonl`。Docker 在汇总前完成容器清理并恢复产物所有权。 [使用与复现](../integrations/robodojo-safety/README.md)

## 短程验证

`smoke` 可显式设置 `evals[].parameters.smoke_control_steps` 缩短单集控制预算。省略该参数时沿用原生预算。短预算及实际终止写入运行证据，便于和标准评测区分。 [Docker 短程验收](../integrations/robodojo-safety/README.md#docker-短程验收)

RTX 4090 Docker 实测通过无接触、左右 ARX `link3` 接触和落球与桌面接触检查。真实 `stack_bowls` 短程评测开启探头后记录 240/240 个物理子步及三个碗的位姿。关／开／关各跑一集、24 个控制步，原生结果和执行动作一致。两个峰值力指标在静置碗的支撑冲量不可读时标为 `unavailable`。 [实测结果](../integrations/robodojo-safety/README.md#2026-11-10-docker-实测记录)

Ruff 检查及格式检查通过。Linux pytest 70 项通过、1 项跳过，macOS 源码包 69 项通过、2 项跳过。源码包在干净目录完成锁定安装，并成功构建编排包和 SDK wheel。
