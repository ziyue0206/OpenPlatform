# OpenPlatform v0.2.0 预览版

## 发布内容

- **RoboDojo 安全探头。** 在固定上游的 Linux RTX Conda 配方上，设置 `collection.safety: true` 即可随同一条原生 rollout 采集接触、实际物理步长、自碰撞和三个目标碗的世界位姿。逐步记录与逐集指标分别写入 `safety-events.jsonl` 和 `safety-metrics.jsonl`，含覆盖状态和证据引用。视频、动作轨迹和安全采集可以分别启用。 [配置与 JSONL 示例](../integrations/robodojo-safety/README.md)
- **Docker 默认配方。** 使用固定的 RoboDojo 镜像运行仿真，模型使用宿主机的独立 Python 环境。该配方通过单集 smoke 和 5 集多布局验收。原生 `full` 配额为 25。 [Docker 安装指南](../integrations/robodojo-docker.md)
- **版本与兼容性。** 编排包为 `0.2.0`，SDK 为 `0.1.0`。安全采集默认关闭，既有提交可沿用原配方。

## 验收范围

| 验收项 | 已有结果 |
| --- | --- |
| 源码包，macOS arm64 CPU | 从 ZIP 解压后完成锁定安装、两份 wheel 构建、Ruff、双环境 SDK 握手和 `dummy` smoke。pytest 67 项通过、2 项需要固定 RoboDojo checkout 的测试跳过。 |
| 安全探头，Linux CPU | 带固定 RoboDojo checkout 的回归为 68 项通过，1 项仅适用于 macOS 的测试跳过。 |
| Docker，Linux RTX | 复用固定镜像，单集 smoke 和 5 集多布局通过，已核对视频、轨迹与取消后的清理。 |
| 安全探头，Linux RTX Conda | `stack_bowls`、ARX X5 joint、单环境、seed 0、布局 0。开启组完整记录 8,000 个物理子步。与两次关闭组相比，原生结果和 800 条执行动作一致。 |
| 独立 PhysX 信号场景 | 验证有效无接触、落球–桌面和左右 ARX `link3` 接触。 |
